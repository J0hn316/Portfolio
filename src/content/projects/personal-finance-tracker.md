## Project Overview

Personal Finance Tracker is a Django web application
designed to help users organize and manage financial
transactions.

## Why I Built It

I built this application to strengthen my Django
development skills and practice creating software
that works with structured relational data.

## Technical Implementation

The application uses Django for its server-side
functionality and SQLite for data persistence.

I worked with Django models, forms, views, templates,
and automated tests while developing the project.

## Challenges and Solutions

The development process involved troubleshooting
form validation and test failures.

Detailed examples of those problems and their
solutions will be added during the case-study phase.

## What I Learned

This project reinforced my understanding of Django
application architecture, relational data,
validation, debugging, and automated testing.
